An AI Worth Using Podcast x OpenClaw 2.0 hackathon, hosted by AgentCribs: build
an OpenClaw 2.0 agent in **multiplayer mode** that fills a real startup role.

## The three requirements

An entry qualifies only if all three hold:

1. **A real job.** The agent owns a role you actually need filled — an SDR, an
   investor-relations lead, a recruiter. It does the work, it is not a mock-up
   and it is not a demo of work.
2. **Published on the Agent Index**, publicly available and MIT licensed, so
   other people can run it.
3. **Qualified through real usage.** The leaderboard ranks by installs and
   reported token usage, and a top entry gets a short verification call to
   confirm the problem is real.

**Multiplayer mode is mandatory**: build something employees, customers or
vendors will interface with. A single-user tool is not an entry.

## The prizes

First place, or one member of the winning team:

- a flight to San Francisco with accommodation for **up to two** team members
- an invitation to AgentCribs with Peter Steinberger (OpenClaw's creator) and
  Tom Preston-Werner (GitHub co-founder) on October 6
- a live demo to the AgentCribs developer community
- two engraved special-edition Mac Minis — one for you, one for your agent's
  top user

If you cannot travel, you demo your agent for Tom and Sam on an AI Worth Using
podcast segment instead.

## The rules that decide an entry

- Up to **four** people per team; travel is funded for up to two.
- Entrants must be 18+ and confirm they can be in San Francisco on October 6 —
  or record the podcast segment before the event.
- MIT licensed, and reporting usage through the
  [AI Worth Using client](https://github.com/plow-pbc/agent-index-client).
- A demo video of **60 seconds or longer**.
- **No spam or artificial usage.**

## Can you use an agent that is not Plow

Yes, but the trade is stated: building on Plow gives you the base image, which
automatically enables iMessage support and Latch — which is what lets your
agent safely control your Mac. See
[the publish page](/skills/how-to-publish-your-agent-on-the-agent-index.md).

## How OpenPlow is positioned for it

OpenPlow is a **first-hire support agent**: it owns a real role (customer
support) end to end, from the customer message to a cited answer or a durable
case, and it is MIT licensed with usage reporting already wired.

Two things stand between this repository and an entry, and both are
engineering, not policy:

- **Multiplayer mode.** The three roles are internal to one Gateway; the
  customer is the multiplayer surface today. Whether that satisfies the rule is
  the owner's call, not a support agent's.
- **A public image and 1-click install.** No image has been pushed, so the
  index listing exists but nobody can install it from the leaderboard.

The score rewards depth, not breadth: a valid user is 200k+ tokens and active
in the last 28 days, so an agent that answers in three turns does not produce
one. See [the Agent Index](/concepts/agent-index.md).
